# Desert Order Bot

A Python project exploring computer vision and desktop automation for the game *Desert Order*.

## Features

- **Unit builder:** Uses an image classifier to recognize game states, click when the build queue is available, and pause when a captcha appears.
- **Attack detection:** Monitors the game screen for attack indicators and sends alerts.

## Technical work

The project combines image classification and computer vision with screen capture, event detection, and automated mouse input. It uses Python tools including OpenCV, TensorFlow/Keras, and PyAutoGUI.
